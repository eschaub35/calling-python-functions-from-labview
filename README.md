# Calling Python Functions from LabVIEW

A bridge enabling LabVIEW applications to call Python functions through a Python server.

## Overview

This project provides a communication interface between a LabVIEW client and a Python server, allowing LabVIEW applications to execute Python functions remotely.

## Architecture

- **LabVIEW client:** Sends requests to the Python server.
- **Python server:** Receives requests, executes Python functions, and returns results.

## Features

- Call Python functions from LabVIEW.
- Keep Python functionality separate from the LabVIEW application.
- Extend the server with custom Python functions.
